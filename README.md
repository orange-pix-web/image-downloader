# AI 图片顺序下载器

用于 Chrome / Edge 的 Manifest V3 扩展，支持 ChatGPT 与豆包。它既能手动下载当前对话中的生成图，也能自动执行“上传产品图 → 发送 Markdown 提示词 → 等待全部图片出现 → 按产品名下载”的批量任务。

扩展会记录成功下载的图片 ID。再次扫描时会自动过滤已经下载过的图片；需要重新下载时，可点击“清空下载记录”。

手动下载弹窗会显示当前页面生成图的缩略图和原始序号。新图片默认勾选，带历史记录的图片默认不选并显示“已下”。可以全选、只选未下载、取消、反选或按编号范围选择；取消部分图片不会改变剩余图片的网页原始编号。

插件发起的普通下载会按下载任务ID锁定目标路径，例如 `ChatGPT图片/禽益生_010.png`。豆包官方保存下载使用独立的改名通道，二者不会互相覆盖，也不会改名用户在浏览器中发起的其他下载。

## 自动任务

1. 刷新 ChatGPT 或豆包页面后，点击网页右侧的“生图”悬浮按钮；也可以点击扩展图标，再点击“打开自动生图任务管理器”。
2. 多选产品图片，再多选对应的 Markdown 提示词。
3. 文件按产品名称自动匹配，例如 `百虫铩.png` 对应 `百虫铩-生图提示词-v2.md`；分组文件 `复合多维益肠化毛片-生图提示词-第01组.md`、`第02组.md` 会共同匹配 `复合多维益肠化毛片.png`。也支持 `鸽虫净-无文案产品图提示词-第01组.md` 前缀匹配 `鸽虫净.png`；存在多个候选时优先最长产品名，仍冲突则停止匹配并提示。
4. 设置轮询间隔、最大等待时间和稳定确认次数。
5. 保持一个已登录的 ChatGPT 或豆包对话页面打开，点击“开始执行”。

## 参考图与提示词预设

- 可同时选择产品图、参考图和 Markdown。发送顺序固定为“参考图在前、产品图在后”。
- 参考图配对支持：单张参考图全部共用、多张参考图按产品名匹配、全部参考图用于每个产品。
- 同名参考图可命名为 `鸽虫净-参考图-01.png`、`鸽虫净-构图参考-02.png`，它们会自动对应 `鸽虫净.png`。
- 内置“产品与品牌替换”“仅参考构图重新生成”“原始 Markdown”三种预设，也可编写自定义模板。
- 不选择 Markdown 时，也可由内置预设或固定提示词直接为每张产品图建立任务，并自定义生成数量。
- 自定义模板支持 `{产品名}`、`{品牌名}`、`{指定文案}`、`{Markdown提示词}`、`{参考图数量}`、`{产品图序号}`、`{生成数量}`。
- 固定提示词可以前置、后置或完全替代 Markdown，并自动保存在扩展设置中。
- “参考图禁用文字”可为全部产品设置旧品牌/旧品名；“按产品设置旧文字”支持每行 `禽益生=禽一片`，插件会强制删除旧文字并统一使用目标产品名。
- 可启用独立“图片声明”，选择写入生图提示词、下载时精确叠加或两者同时。下载叠加支持底部居中/左右、字号、透明度、淡色背景，以及扩展底部声明区避免遮挡主体。
- 声明设置会进入任务和下载历史指纹；修改文字、位置或样式后可重新生成并下载。豆包原生保存无法后期叠字时会自动改用提示词声明。
- 历史任务指纹包含参考图、预设及最终提示词；更换任意一项都会建立新任务，不会被旧记录错误跳过。

管理器顶部会显示并锁定本批任务使用的对话标签页。即使同时打开多个 ChatGPT/豆包窗口，插件也不会自动切换到其他活动页；需要换页时，必须在管理器中手动选择并点击“绑定所选页面”。绑定页关闭或失效时任务会暂停。

可开启“每个任务使用新对话”。启用后，每条提示词发送前都会在绑定标签页进入全新对话；使用自定义 GPT 时会保留对应 GPT，不会切换成普通 ChatGPT。恢复已经处于等待或下载阶段的任务时不会重复新建对话。

豆包适配器支持正文分段图片和原生图片网格。两种结构都只使用页面地址定位图片，实际下载会打开预览并使用豆包官方“保存”按钮获取原图。扩展根据下载内容的实际 MIME 自动使用 `.png`、`.jpg` 或 `.webp` 后缀，JFIF/JPEG 统一使用标准 `.jpg`。

扩展会从 Markdown 的代码块提取完整提示词，并从“生成9张”等文字识别预期数量。只有停止生成、预期图片全部出现且连续多次检查保持稳定后才会开始下载。文件名使用产品名称，如 `百虫铩_001.png`。

如果提取后的提示词末尾包含以下固定句子，扩展会精确移除：

- `请按模板编号【01、02、03、04、05、06、07、08、09】依次生成9张独立图片。`
- `每完成一张都重新读取对应提示词……输出前逐张核对产品名称、包装和全部指定中文。`

其他结尾、其他段落和不含这些固定句的提示词不会被改动。

已完成任务会写入历史，再次导入相同产品图和相同提示词时自动跳过。任务失败会暂停队列，避免产品、提示词和生成结果错位。

每个产品都可以单独设置起始编号。比如将“禽益生”设为 `010`，预期9张时会保存为 `禽益生_010.png` 至 `禽益生_018.png`。同一产品如果有多个提示词任务，后续任务会自动接着编号。产品起始编号会保存，下次导入时自动恢复，并作为任务历史的一部分。

ChatGPT/豆包网页右侧保留“生图”入口按钮，点击后打开或聚焦独立的任务管理窗口。

## 任务恢复与自动刷新

“生图”按钮现在打开独立的扩展任务窗口，刷新 ChatGPT 或豆包目标页面不会关闭任务窗口。任务、产品图片、提示词、当前阶段、基线图片 ID 和刷新次数保存在扩展 IndexedDB 中；重新打开任务窗口时可以恢复。

在“等待生成”阶段，如果默认连续5分钟没有出现任何新图片，扩展会先保存状态，再刷新目标 AI 标签页。页面重新连接后继续扫描当前任务，不会再次上传或发送提示词。每出现一张新图片都会重置无进展计时；默认最多自动刷新2次，达到上限后暂停任务。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`，或 Edge 的 `edge://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹 `GPT图片顺序下载器`。
5. 刷新已经打开的 ChatGPT 页面。

## 使用

1. 打开需要下载图片的 ChatGPT 对话。
2. 最好先从上往下滚动一遍，让懒加载图片进入网页。
3. 点击浏览器工具栏中的扩展图标。
4. 确认扫描出的图片数量，点击“按顺序下载全部图片”。

图片默认保存到浏览器下载目录下的 `ChatGPT图片` 文件夹，名称依次为：

`GPT图片_001.png`、`GPT图片_002.png`、`GPT图片_003.png`……

浏览器如果开启了“下载前询问每个文件的保存位置”，批量下载时可能连续弹窗，建议暂时关闭该选项。
